Mini Library Catalog
Project Overview

The Mini Library Catalog is a simple library management system developed using the C Programming Language. It helps manage library book records efficiently by providing features such as searching, borrowing, returning, adding, and removing books.

The main purpose of this project is to reduce manual work, improve record management, and make library operations easier for small libraries and educational institutions.

 Objectives

- To automate basic library operations using C.
- To add, search, update, and delete book records.
- To manage book borrowing and returning.
- To understand file handling and structured programming.
- To improve logical thinking and data management skills.

Features

-  User Login
-  Search Books
-  Borrow Books
-  Return Books
-  Add Books
-  Remove Books
-  View Library Records
-  Store and Retrieve Data Using Text Files

Technologies Used

- Programming Language: C
- Compiler: GCC / Turbo C / Code::Blocks / Dev-C++
- Operating System: Windows / Linux
- Concepts: Structures, Functions, Arrays, Loops, Conditional Statements, and File Handling

 System Requirements

Hardware Requirements

- Processor: Intel Core i3 or higher
- RAM: Minimum 4 GB
- Storage: At least 500 MB free space

Software Requirements

- Windows or Linux Operating System
- C Compiler such as GCC
- Code Editor or IDE

 Project Modules

1. Input Module

Collects user information, login details, and book details.

2. Processing Module

Handles authentication, book searching, borrowing, and returning operations.

3. Output Module

Displays search results, confirmation messages, and error messages.

4. File Handling Module

Stores and retrieves library data using text files.

Example files:

- "books.txt"
- "users.txt"
- "transactions.txt"

Concepts Used

- Structures: Store book details such as ID, title, author, and status.
- Functions: Divide the program into smaller, manageable tasks.
- Arrays: Store multiple book and user records.
- Loops and Conditional Statements: Control program flow and process records.
- File Handling: Save and retrieve data using functions such as "fopen()", "fprintf()", "fscanf()", and "fclose()".

  
 Results

The project report describes the system as successfully supporting user login, book searching, borrowing, returning, and saving and retrieving data.

Testing indicated accurate search results and correct updates to book status for small datasets.
